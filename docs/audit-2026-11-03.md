# Technical and SEO audit, 3 Nov 2026

Checked on a local production build (852 pages scanned by script, Lighthouse mobile) and on the live Vercel deployment (all 840 sitemap URLs crawled, Google Rich Results Test on a product page).

## Fixed
| Area | Before | After |
|---|---|---|
| Crawlable links | 1 real link per page (menu, tiles and cards were click handlers) | 75 to 360 per page, real `<a href>` |
| Structured data | 12 of 852 pages | Organization, WebSite, BreadcrumbList, Product + Offer, CollectionPage/ItemList, Article on every indexable page; Rich Results Test: Product snippets, Merchant listings, Breadcrumbs valid |
| Social image, favicon | none | default OG image, product photo on product pages, SVG + Apple icon |
| Accessibility | skip link missing, nested `<main>`, unnamed buttons, unbound labels, heading skips, low contrast | all fixed; Lighthouse accessibility 96 to 100 on the pages tested |
| Titles / meta | 457 titles over 66 characters | none over 66 in the scan |
| Security headers | none | CSP, HSTS, nosniff, frame, referrer, permissions, Link header |
| robots.txt | basic | AI crawlers listed, Content-Signal (search yes, AI input yes, AI training no) |
| Sitemap lastmod | build time on every deploy | fixed content date (`CONTENT_UPDATED` in `src/lib/seo.ts`) |
| Agent layer | none | `llms.txt`, `auth.md`, all `.well-known` files, read-only JSON API, MCP endpoint (`/api/mcp/`), `webmcp.js` |
| Images | full-size photo on every card | small variants (`*-s.webp`) for cards and thumbnails |

## Still open
- Performance 86 to 98 on mobile: the product data ships to the browser in one script. Needs a server-component refactor.
- Image cache is 24 hours (file names are not versioned).
- Invented company details in the footer and Impressum (WEEE, LUCID numbers, GmbH & Co. KG name); "2%" vs "10%" crypto discount; JobRad claims.
- Shipping details are not in the product data because shipping terms are not confirmed.
- Domain e-bike-zuverkaufen.de must be live with HTTPS before canonicals and sitemap point at a working site.
